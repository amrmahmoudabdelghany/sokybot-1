# Sokybot Infrastructure

This directory contains shared infrastructure and utilities.

## Modules
- **`sokybot-commons`**: Shared utilities (Hexdump, Bytes, etc.).
- **`sokybot-persistence`**: Database access layer (Hibernate/JPA).
- **`sokybot-settings`**: Configuration management.
- **`sokybot-dist`**: Final distribution packaging (Karaf assembly).
- **`sokybot-features`**: Karaf Feature definitions.
