# Sokybot Game

This directory contains game-specific data structures, logic, and file format handlers.

## Modules
- **`sokybot-pk2` / `sokybot-pk2-extractor`**: Handling of PK2 archive format.
- **`sokybot-game-model`**: Domain objects representing game entities (Characters, Items, Mobs).
- **`sokybot-game-events`**: Event definitions and packet-to-event translators.
- **`sokybot-game-navigation`**: Pathfinding and NavMesh handling.
- **`sokybot-game-loader`**: Logic for loading the game client.
