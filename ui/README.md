# Sokybot UI

This directory contains the User Interface components, both Web and Desktop.

## Modules
- **`sokybot-webview`**: The modern React+TypeScript frontend.
- **`sokybot-http-server`**: Backend API for the web interface.
- **`sokybot-swing`**: Legacy/alternative Swing components.
- **`sokybot-dev-tools`**: Developer utilities for inspection and debugging.
